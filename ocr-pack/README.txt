Akkhor PDF Editor - OCR language pack (Bangla + English)
========================================================

What this is
  Language data for text recognition (OCR) in Akkhor PDF Editor, so scanned
  pages can be searched, selected and copied. Installed for your Windows
  account only, in:
    %LOCALAPPDATA%\Akkhor PDF Editor OCR\tessdata

  The OCR engine itself (Tesseract) is already inside Akkhor PDF Editor.
  This pack adds only the trained language models:
    ben.traineddata  Bangla   (tessdata_best)
    eng.traineddata  English  (tessdata_best)

Where the data comes from
  The Tesseract project: https://github.com/tesseract-ocr/tessdata_best
  Licensed under the Apache License 2.0 (see LICENSE-tessdata.txt).

Privacy
  Nothing is downloaded or sent anywhere, by this installer or by the app.

To remove it
  Windows Settings > Apps > "Akkhor PDF Editor OCR Pack" > Uninstall.
